## Процедура создания коммита с проверками

При создании коммита автоматически запускаются проверка линтерами `stylelint`, `eslint` и форматирование `prettier`.

Если линтер обнаружит ошибки:

- Коммит создан не будет
- Необходимо исправить все выявленные проблемы
- Добавить исправленные файлы в индекс: `git add .`
- Повторить коммит

**Рекомендация:**  
Для предотвращения ошибок на этапе коммита предварительно выполните:  
`npm run lint`. Это позволит выявить и исправить проблемы до создания коммита.

Есть также команды для запуска проверок по отдельности:

- `npm run eslint` - запускает проверку линтера и исправляет проблемы, которые можно исправить автоматически,
- `npm run stylelint` - запускает проверку литера для файлов стилей и исправляет проблемы, которые можно исправить автоматически,
- `npm run prettier` - исправляет ошибки форматирования кода.

Можно добавить автозапуск этих команд при сохранении файла в вашей IDE.

Для создания коммита рекомендуется запускать команду `npm run commit`. Она позволяет обеспечить соответствие описаний коммитов [общепринятым соглашениям](https://www.conventionalcommits.org/en/v1.0.0/).

В проекте настроены алиасы, которые можно использовать при импорте модулей:

```
	alias: {
		'@': path.resolve(__dirname, './src'),
		'@components': path.resolve(__dirname, './src/components'),
		'@services': path.resolve(__dirname, './src/utils'),
		'@pages': path.resolve(__dirname, './src/pages'),
		'@utils': path.resolve(__dirname, './src/utils'),
	},
```

# 🚀 Stellar Burgers — Космическая Бургерная

 SPA-приложение для заказа космических бургеров. Разработано на стеке **React 18**, **TypeScript**, **Redux Toolkit** и **Vite**. В рамках текущего этапа проведена глубокая оптимизация продакшен-бандла, настроено SEO и внедрено комплексное автоматизированное тестирование.

---

## 🛠 Выполненные задачи и архитектурные фичи

1. **Модульное тестирование (Vitest):** Покрыта вся бизнес-логика приложения (редюсеры, начальные состояния и мемоизированные селекторы). Написаны тесты для асинхронных Thunks с изолированием сетевого слоя, а также интеграционные тесты для кастомного `WebSocket Middleware` с использованием Fake Timers.
2. **Сквозное тестирование (Playwright):** Настроены стабильные кроссбраузерные E2E-сценарии для Chromium, Firefox и Webkit. Проверены механизмы Drag-and-Drop, управление двухрежимным роутингом модальных окон и интерфейс страниц.
3. **Code Splitting & Оптимизация:** Все страницы переведены на ленивую загрузку (`React.lazy` + `Suspense`), бандл разбит на независимые чанки.
4. **SEO-оптимизация:** Интегрирован пакет `react-helmet-async`, настроен универсальный переиспользуемый компонент для динамического управления метатегами и заголовками вкладок.

## 💻 Скрипты для запуска и проверки

Перед запуском убедитесь, что все зависимости установлены командой `npm install`.

### ⚡️ Разработка и Сборка

- `npm run dev` — Запуск локального сервера разработки (Vite).
- `npm run build` — Финальная production-сборка проекта.

### 🧪 Запуск тестов

- `npm run test` — Запуск **Unit-тестов в Vitest** (67 тест-кейсов для слайсов, селекторов и middleware).
- `npx playwright test` — Запуск **E2E-тестов в Playwright** (21 тест-кейс для проверки UI, DND и модалок).
- `npx playwright test --ui` — Запуск E2E-тестов в интерактивном графическом интерфейсе Playwright.
